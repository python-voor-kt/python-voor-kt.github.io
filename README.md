# Python voor KT

De gepubliceerde website staat op **<https://python-voor-kt.github.io>**.

Deze repository bevat alleen het **gegenereerde resultaat** van die site: HTML,
CSS en media die automatisch uit een bronrepository worden gebouwd. Er staat
hier dus geen broncode die je zinvol kunt lezen of aanpassen, en de inhoud van
deze repository wordt bij elke publicatie volledig overschreven.

## Een fout melden of een vraag stellen

Dat kan wél hier, en dat stellen we op prijs.

Ga naar de [issues-pagina](../../issues) en kies een sjabloon:

| Sjabloon | Waarvoor |
| --- | --- |
| Fout melden | Er staat iets verkeerds, of een instructie werkt niet. |
| Uitleg is onduidelijk | De tekst klopt misschien wel, maar je komt er niet uit. |
| Nieuw onderwerp voorstellen | Er ontbreekt uitleg over iets dat je nodig hebt. |

Je hoeft geen ervaring met GitHub te hebben: je vult een paar vragen in en klikt
op verzenden. Meldingen van studenten zijn juist waar we het meeste aan hebben —
loop je ergens tegenaan, dan geldt dat vrijwel zeker ook voor je jaargenoten.

## Pull requests

Die kunnen we hier niet gebruiken, omdat wijzigingen in deze repository bij de
eerstvolgende publicatie verdwijnen. Wil je een tekstvoorstel doen, zet het dan
in een issue.
