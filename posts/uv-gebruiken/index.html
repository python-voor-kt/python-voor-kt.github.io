uv is een project- en pakketmanager voor Python. Deze handleiding laat je zien hoe je met uv een project aanmaakt en pakketten installeert vanuit de Terminal.

uv zorgt voor

  • eenvoudige aanmaak en management van virtual environments;
  • installatie van verschillende versies van Python;
  • snelle installatie van Python-pakketten;
  • afstemming van versies van dependencies;
  • reproduceerbare installaties via een lockfile.

Voorbereiding

Zorg dat je uv hebt geïnstalleerd. Zie deze handleiding.

Tip

Veel programmeer-programma’s, waaronder Positron, hebben ook een eigen (eenvoudigere) manier om projecten aan te maken. We hebben een handleiding voor projecten in Positron geschreven.

Een Terminal openen

Alle commando’s in deze handleiding draai je in een Terminal (macOS) of PowerShell (Windows), vanuit de map waar je project staat of moet komen.

In Positron

Heb je je project al open in Positron, gebruik dan de ingebouwde terminal. Die staat meteen in de map van je project, dus je hoeft niet meer met cd naar de map te gaan.

  1. Klik onderin het paneel op het tabblad terminal, of klik in het menu op Terminal → New Terminal.
  2. Zie je het onderste paneel niet? Klik dan in het menu op View → Appearance → Panel, of gebruik Ctrl+` (Windows) of Cmd+` (macOS).

Buiten Positron

  • Windows
  • macOS

  1. Klik op het Windows-menu, type PowerShell, en klik op ‘Windows PowerShell’ of druk op de Enter-toets.

  2. Ga naar de map waar je wil werken met cd, waarbij je <pad> vervangt door de locatie van de map. Bijvoorbeeld: cd C:\Gebruikers\voorbeeld\Studie\programmeren.

    cd <pad>

  1. Open Spotlight met Cmd+Spatie, type Terminal en druk op Enter.

  2. Ga naar de map waar je wil werken met cd, waarbij je <pad> vervangt door de locatie van de map. Bijvoorbeeld: cd ~/Studie/programmeren.

    cd <pad>
Waarschuwing 1: OneDrive (Windows) en andere cloudopslag

Zet een uv-project nooit in OneDrive. Microsoft Windows gebruikt tegenwoordig OneDrive als standaard locatie voor documenten. OneDrive werkt met ‘cloudbestanden’, die niet altijd daadwerkelijk op je computer staan. Zelfs als de bestanden wel op je computer staan, worden ze niet als normale bestanden behandeld.

Dit kan ook gelden voor bestanden op bijvoorbeeld Dropbox.

Een goede locatie is een map in C:\Gebruikers\<gebruikersnaam>\, bijvoorbeeld C:\Gebruikers\<gebruikersnaam>\Studie (maar niet C:\Gebruikers\<gebruikersnaam>\Documenten).

Heb je wel eerder een project in OneDrive gezet, draai dan uv cache clean in je Terminal/PowerShell. uv deelt bestanden tussen projecten, waardoor een project in OneDrive ook problemen kan veroorzaken in je andere projecten. uv cache clean ruimt dat op.

Project aanmaken

Het is aangeraden voor elk project (onderzoek, stage, vak, opdracht, spontaan idee) een nieuw uv-project aan te maken. Hier beschrijven we de methode die alleen gebruik maakt van de Terminal/PowerShell.

Tip 1: Regels voor projectnamen

De naam van een projectmap moet aan bepaalde regels voldoen.

  • De naam moet beginnen én eindigen met een letter.
  • De naam mag alleen letters, cijfers, _, - en . (underscore, streepje en punt) bevatten.

Nieuw project

  1. Open een Terminal/PowerShell en ga naar de bovenliggende map waarin je je project wil maken. Als de projectmap C:\Gebruikers\<gebruikersnaam>\Studie\programmeren\project-1 moet worden, ga je dus naar C:\Gebruikers\<gebruikersnaam>\Studie\programmeren.

  2. Draai onderstaand commando, waarbij je <projectnaam> vervangt door de naam van je project — in het voorbeeld hierboven dus uv init project-1. De naam moet voldoen aan de regels voor projectnamen. Dit maakt een nieuwe map, en zet daar de benodigde bestanden in.

    uv init <projectnaam>
OpmerkingPython-versie

Standaard gebruikt uv de meest recente Python-versie voor het nieuwe project. Dit is meestal wenselijk. Soms, vooral als er net een nieuwe versie is vrijgegeven, is het wenselijk om een oudere (meer stabiele) versie te gebruiken. Je kunt een Python-versie kiezen door --python <versie> achter het uv init-commando te zetten, waarbij je <versie> vervangt door bijvoorbeeld 3.12 of 3.13.9.

Bestaand project zonder pyproject.toml-bestand

Als je een bestaande projectmap hebt, maar nog geen pyproject.toml-bestand, volg dan deze instructies.

  1. Open een Terminal/PowerShell en ga naar de projectmap. Let op dat de naam van de map voldoet aan de regels voor projectnamen.

  2. Draai onderstaand commando. Dit maakt in deze map de benodigde bestanden aan.

    uv init

Bestaand project dat al een pyproject.toml-bestand heeft

Als je al een projectmap met een pyproject.toml-bestand hebt, volg dan deze instructies.

  1. Open een Terminal/PowerShell en ga naar de projectmap. Let op dat de naam van de map voldoet aan de regels voor projectnamen.

  2. Draai onderstaand commando. Dit vertelt uv dat je al een project hebt, en om een virtual environment aan te maken op basis van het pyproject.toml-bestand.

    uv sync
OpmerkingVirtual environments

Een virtuele omgeving (virtual environment, vaak afgekort met venv) is een aparte ‘virtuele’ installatie van een specifieke versie van Python. Hierin installeer je alle Python-pakketten die je voor een project nodig hebt. Dit zorgt ervoor dat je de juiste versies van alle dependencies installeert voor het juiste project. Als je voor Project A bijvoorbeeld een pakket nodig hebt dat een ‘oudere’ versie van NumPy (<2.0) gebruikt, en Project B juist gebruik wil maken van de nieuwste mogelijkheden van NumPy (2.0 of nieuwer), kunnen deze projecten niet gebruik maken van dezelfde installaties. Door ze beiden in een eigen virtual environment te draaien, heb je dit probleem niet.

Pakketten installeren

Je kunt pakketten aan je installatie toevoegen met onderstaand commando, waarbij je <naam> vervangt door de naam van het pakket. Je kunt meerdere pakketten toevoegen door meerdere namen achter elkaar te plaatsen, bijvoorbeeld uv add numpy scipy matplotlib pandas.

uv add <naam>

uv voegt het pakket toe aan de lijst met dependencies in pyproject.toml, en installeert het pakket en al zijn dependencies.

Je kunt ook pakketten installeren met uv pip install <naam>. Dit installeert een pakket wel, maar voegt het niet toe aan de dependencies van het project. Daarmee is de installatie niet reproduceerbaar. Dit kan nuttig zijn om bijvoorbeeld een pakket uit te proberen, of tijdelijk te installeren en daarna weer te verwijderen.

OpmerkingDependencies

Python-projecten maken meestal gebruik van andere Python-pakketten. Dit heet een dependency. Als je bijvoorbeeld matplotlib installeert, worden er ook negen dependencies, pakketten waar matplotlib gebruik van maakt, geïnstalleerd. Eén van deze pakketten heeft weer een eigen dependency, die ook wordt geïnstalleerd. Dit heet samen een dependency tree. Met het terminal-commando uv tree kan je deze voor je eigen project weergeven.

Bij installatie van pakketten is het belangrijk dat alle pakketten in de dependency tree goed met elkaar samenwerken. Het kan bijvoorbeeld zijn dat pakket A en pakket B beiden pakket C als dependency hebben, waarbij pakket A kan werken met pakket C versie 1.2 tot 2.7, terwijl pakket B werkt met pakket C versie 2.0 tot 3.1. Een goede project-manager zorgt voor goede afstemming tussen versies, en stopt de installatie als er geen afstemming mogelijk is.1

OpmerkingLockfile

uv maakt voor geïnstalleerde projecten altijd een lockfile aan. Hierin staat nauwkeurig beschreven welke versie van elk pakket in het project gebruikt is. Hierdoor kan de virtual environment exact gereproduceerd worden op dezelfde én andere computers.

Voetnoten

  1. De standaard manier om Python-pakketten te installeren, pip, zorgt niet voor afstemming tussen versies, maar installeert een versie die werkt voor het meest recent geïnstalleerde pakket. Dit kan soms tot problemen leiden.↩︎
