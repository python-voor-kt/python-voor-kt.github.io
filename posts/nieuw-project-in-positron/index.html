Om te zorgen dat je bestanden goed georganiseerd blijven, is het belangrijk voor elk project een nieuwe projectmap aan te maken. Dit voorkomt (later) veel problemen.

Voorbereiding

Deze handleiding gaat er vanuit dat je uv en Positron hebt geïnstalleerd. Zie de installatiehandleidingen voor uv en Positron.

Locatie van je projectmap

Het is een goede gewoonte voor elk onderzoek, vak, opdracht of stage een nieuw project aan te maken. Je project komt in een projectmap te staan. Zet deze op een logische locatie, bijvoorbeeld in een map Studie in de map van het gebruikersaccount op je computer.

Voor Windows-gebruikers is dit een goede beginlocatie:
C:\Gebruikers\<gebruikersnaam>\Studie

Voor macOS-gebruikers is dit een goede beginlocatie:
/Users/<gebruikersnaam>/Documenten/Studie

De projectmap komt in deze beginlocatie te staan, dus bijvoorbeeld:
C:\Gebruikers\<gebruikersnaam>\Studie\ProjectA of
/Users/<gebruikersnaam>/Documenten/Studie/KT1355/opdracht_x.

Waarschuwing 1: OneDrive (Windows) en andere cloudopslag

Microsoft Windows gebruikt tegenwoordig OneDrive als standaard locatie voor documenten. uv werkt niet goed als je je bestanden in OneDrive zet. OneDrive werkt namelijk met ‘cloudbestanden’, die niet altijd daadwerkelijk op je computer staan. Zelfs als de bestanden wel op je computer staan, worden ze niet als normale bestanden behandeld.

Dit kan ook gelden voor bestanden op bijvoorbeeld Dropbox.

Zet je projectmap dus nooit in OneDrive, en dus ook niet in je standaard ‘Documenten’-locatie. Een goede locatie is een map in C:\Gebruikers\<gebruikersnaam>\, bijvoorbeeld C:\Gebruikers\<gebruikersnaam>\Studie (maar niet C:\Gebruikers\<gebruikersnaam>\Documenten).

Heb je wel eerder een project in OneDrive gezet, draai dan het commando uv cache clean in je Terminal/PowerShell. uv deelt bestanden tussen projecten, waardoor een project in OneDrive ook problemen kan veroorzaken in je andere projecten. uv cache clean ruimt dat op.

Tip 1: Regels voor projectnamen

De naam van een projectmap moet aan bepaalde regels voldoen.

  • De naam moet beginnen met een letter.
  • De naam moet eindigen met een letter of cijfer.
  • De naam mag verder alleen letters, cijfers, _, - en . (underscore, streepje en punt) bevatten.
  • De naam mag dus geen spaties bevatten.
