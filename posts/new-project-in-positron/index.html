Een nieuw project starten in Positron

Auteur

Marjon van Wees, Menno Bloembergen en Peter Somhorst

Om te zorgen dat je bestanden goed georganiseerd blijven, is het belangrijk voor elk project een nieuwe map aan te maken. Dit voorkomt (later) veel problemen.

Mappenstructuur

Het is een goede gewoonte voor elk onderzoek, vak, opdracht of stage een nieuw project aan te maken. Je project komt in een projectmap te staan. Zet deze op een logische locatie.

WaarschuwingOneDrive (Windows) en andere cloudopslag

Windows gebruikt tegenwoordig OneDrive als standaard locatie voor documenten. uv werkt niet goed als je je bestanden in OneDrive zet. OneDrive werkt namelijk met cloud-bestanden, die niet altijd daadwerkelijk op je computer staan. Zelfs als de bestanden wel op je computer staan, worden ze niet als normale bestanden behandeld.

Dit kan ook gelden voor bestanden op bijvoorbeeld Dropbox.

Zet je projectmap dus nooit in OneDrive. Een goede locatie is een map in C:\Users\<gebruikersnaam>\ (maar niet C:\Users\<gebruikersnaam>\Documenten).

Heb je wel eerder een project in OneDrive gezet, draai dan uv cache clean in je Terminal/PowerShell. uv deelt bestanden tussen projecten, waardoor een project in OneDrive ook problemen kan veroorzaken in je andere projecten. uv cache clean ruimt dat op.

Er zijn verschillende opties om in Positron aan de slag te gaan met een project nieuw project:

  • met een leeg project starten
  • een pyproject.toml-bestand downloaden
  • een git repository clonen
  • bestanden downloaden in een *.zip-bestand

Met een leeg project starten

–installatiehandleiding–

Daarna kan je pakketten installeren. Dit doe je door in de terminal uv add <naam> te draaien, waarbij je <naam> vervangt door de naam van het pakket. Zie ook deze post.

Een pyproject.toml-bestand downloaden

–Zoals hierboven, maar Empty Project

  • Sleep het pyproject.toml-bestand naar de explorer (balk aan de linkerkant) in Positron.
  • Open een Terminal (klik in het menu op Terminal → New Terminal).
  • Draai uv sync. Dit maakt een nieuwe virtual environment voor je project en installeert de juist pakketten.

Het kan zijn dat je hierna Positron opnieuw moet opstarten, omdat Positron niet altijd de nieuwe virtual environment direct herkent.

Een git repository clonen

Je kunt een project starten door een repository te clonen vanaf GitHub of GitLab.

Om een bestanden uit een repository te kunnen downloaden, moet je een URL (link) hebben. Bruikbare URLs zien er als volgt uit:

  • https://<server>/<organisatie>/<repository>
  • git@<server>:<organisatie>/<repository>.git

Hierbij is <server> een van github.com, gitlab.com of gitlab.tudelft.nl. <organisatie> is de organisatie die de repository beheert. <repository> is de naam van de repository.

WaarschuwingClonen vs. downloaden

Deze instructie is voor het clonen van een repository. Dit betekent dat je een connectie behoud met de repository, en bijvoorbeeld de geschiedenis van de bestanden kunt inzien, en kunt bijdragen aan wijzigingen aan de repository.

Het kan zijn dat je slechts de bestanden wil downloaden die in de repository staan. Download dan de bestanden uit de *repository:

  • Open de https://-link
  • Klik op de ‘Code’-knop (groen in GitHub, blauw in GitLab)
  • Klik op ‘Download ZIP’ (GitHub) of ‘zip’ onder ‘Download source dode’ (GitLab)
  • Vervolg de instructies hier
  • Klik op New → New Folder from Git…
  • Plak de URL in het bovenste veld.
  • Selecteer de juiste locatie voor de projectmap.
  • Klik OK. Wacht tot de repository gecloned is en opent.
  • Er kan je gevraagd worden of je de auteurs van de repository vertrouwd. Klik alleen op ‘Yes, I trust the authors’ als je erop vertrouwd dat het veilig is de code veilig op je eigen computer te draaien.
  • Open een Terminal (klik in het menu op Terminal → New Terminal).
  • Draai uv sync1. Dit maakt een nieuwe virtual environment voor je project en installeert de juist pakketten.
  • Het kan zijn dat Positron (rechts onderin) vraagt of je “We noticed a new environment has been created. Do you want to select it for the workspace folder?”. Klik op ‘Yes’.
  • Als dit niet gevraagd wordt, kan het zijn dat je Positron opnieuw moet opstarten. Positron herkent niet altijd de nieuwe virtual environment direct.

Bestanden uit een *.zip-bestand

Het kan zijn dat je bestanden als *.zip-bestand krijgt aangeleverd.

Als het *.zip-bestand een pyproject.toml-bestand bevat, voer dan de instructies voor het starten met een pyproject.toml-bestand uit. Vervang de stap “Sleep het pyproject.toml-bestand …” door onderstaande instructie.

Als het *.zip-bestand geen pyproject.toml-bestand bevat, maar slechts bestanden die nodig zijn voor het project, voer dan de instructies voor het starten van een leeg project uit. Voer daarna onderstaande instructie uit.

  • Pak het *.zip-bestand uit:
    • Windows: Klik met je rechtermuisknop op het bestand en klik op ‘Alles uitpakken’. Kies de projectmap om de bestanden in uit te pakken.
    • macOS: Dubbelklik op het bestand. Deze wordt automatisch uitgepakt in een map. Verplaats de bestanden uit de map naar de projectmap.

Voetnoten

  1. We gaan er hier vanuit dat het pyproject.toml-bestand compleet is. Soms is bijvoorbeeld de project-naam niet gegeven, omdat het repository voor verschillende projecten gebruikt kan worden. Maak pyproject.toml dan eerst compleet.↩︎
